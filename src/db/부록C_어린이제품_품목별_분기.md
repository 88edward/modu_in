## K-01 아동용 섬유제품 · 공급자적합성확인
- 적용기준: 공급자적합성확인기준 부속서 15 아동용 섬유제품 (+ 어린이제품 공통안전기준)
- 적용범위: 피부에 직접 또는 간접 접촉하는 섬유로 만든 36개월 이상 만 13세 이하 아동용 섬유제품
- 원문: https://www.safetyguide.kr/indct/kid?id=1
- 생활용품 짝(만 14세 이상): 가정용 섬유제품 → **연령 등급 분기**
- 분기:
  - **적용 제외 확인**: 맞춤복이에요 → 대상 아님 / 놀이용 가장복(코스튬)이에요 → K-18로 전환 / 가죽·인조가죽·모피로 된 신발이에요 → K-04로 전환
  - **어떤 종류의 섬유제품인가요?**: 외의류 (재킷, 코트, 점퍼 등) / 중의류 (티셔츠, 바지, 수영복 등) / 내의류 (속옷, 잠옷 등) / 침구류 (이불, 베개, 매트 등) / 신발류 (천·합성수지 신발) / 양말·장갑·모자류 / 가방류 / 방한용·패션용·스포츠용 마스크 … 외 1개
  - **단추·장식처럼 떨어질 수 있는 작은 부품이 달려 있나요?**: 네 / 아니요
  - **신발이 말랑하거나 발포된 합성수지 재질인가요?** (조건: textile_type = shoes): 네 / 아니요
  - **품목 관계** 36개월 미만이면 유아용 섬유제품(K-21)
- 라벨: KC(번호 없음) · 어린이 공통 뼈대 + 추가: 취급상 주의표시
- 주의사항(작은 부품) (조건: small_parts = yes): 1줄 — 작은 부품이 부착된 경우의 주의사항 (부속서 15의 7.2) ⚠원문 확인
- 주의사항(연질·발포 합성수지 신발) (조건: soft_resin_shoes = yes): 1줄 — 연질 또는 발포 합성수지 신발 주의사항 (부속서 15의 7.2) ⚠원문 확인
- 표시 방법: 공통안전기준 표시사항은 제품 표면 또는 최소 포장단위에 한글로, 쉽게 지워지거나 떨어지지 않게 표시
- 표시 방법: 사용상 주의사항·사용설명서는 어린이가 이해하기 쉬운 문구로
- 원문 오류·주의: 표시 예시에 섬유 조성·치수가 없고 작성요령은 부속서 15의 7로 넘김. 유아용 섬유제품(K-21)과 같은 수준의 조성·치수 표시가 필요한지 원문 확인

## K-02 아동용 이단침대 · 안전확인
- 적용기준: 안전확인기준 부속서 5 어린이용 이단침대 (+ 어린이제품 공통안전기준)
- 적용범위: 만 3세 이상 만 13세 이하 가정용 2단 침대. 바닥에서 침대 바닥판까지 800 mm 이상인 1인용 침대도 포함
- 원문: https://www.safetyguide.kr/indct/kid?id=2
- 분기:
  - **적용 제외 확인**: 포장에 "성인을 위한 것" 또는 "어린이용이 아님"이 표시된 2단 침대예요 → 대상 아님
  - **침대 구조가 어떤가요?**: 2단 침대 / 1층짜리지만 바닥판 높이가 800 mm 이상 (로프트형) / 1층이고 바닥판 높이 800 mm 미만
- 라벨: KC + 안전확인신고번호 · 어린이 공통 뼈대 + 추가: 크기·체중의 한계
- 사용설명서 (부속서 5의 6.2): 7줄 — 매트리스 상단이 침대에 표시된 선 위로 올라가지 않도록 하는 설명
- 경고문구: 1줄 — (가이드에는 경고문구가 그림으로만 실려 있음: 부속서 5의 6.1.8 원문에서 문구 확인 필요) ⚠원문 확인
- 표시 방법: 사용상 주의사항(경고문구)은 제품 본체에 부착하고 위치·내용·형태를 눈에 띄게
- 표시 방법: 사용설명서를 부착·제공해야 함

## K-03 어린이용 가구 · 공급자적합성확인
- 적용기준: 공급자적합성확인기준 부속서 14 어린이용 가구 (+ 어린이제품 공통안전기준)
- 적용범위: 생후부터 13세 이하 어린이가 가정·어린이집·유치원·초등학교 등에서 사용하도록 의도된 가구
- 원문: https://www.safetyguide.kr/indct/kid?id=3
- 생활용품 짝(만 14세 이상): 가구(높이 762 mm 이상 서랍장/파일링캐비닛 제외), 가구(높이 762 mm 이상의 가정용 서랍장 및 → **연령 등급 분기**
- 분기:
  - **적용 제외 확인**: 가구 모양의 장난감(가구완구)이에요 → K-18로 전환 / 유아용 식사 의자예요 → K-22로 전환 / 2단 침대예요 → K-02로 전환 / 요람·유아용 침대·놀이 울타리예요 → K-23로 전환 / 실험실용 기자재예요 → 대상 아님
  - **어떤 가구인가요?**: 책상·탁자 / 의자 / 수납가구 (옷장, 서랍장, 책장 등) / 침대 / 소파 / 조립식 가구 (DIY) / 기타 (검색대, 강연대 등)
  - **어느 연령용 가구인가요?**: 영·유아용 (3세 미만) / 어린이용 (3세 이상 ~ 8세 미만) / 학생용 (8세 이상)
  - **떼어질 수 있는 작은 부품이 있나요?**: 네 / 아니요
- 라벨: KC(번호 없음) · 어린이 공통 뼈대 + 추가: 마감재; 구조부재; 표면가공; 쿠션재 [의자·소파·매트리스와 함께 있는 경우에 한함]; 크기·체중의 한계 [크기·체중 제한이 있는 경우]
- 취급상 주의사항 (해당 없는 것이 명백하면 생략·변경 가능): 11줄 — 직사광선 또는 열을 피할 것
- 작은 부품이 있는 가구 (조건: small_parts = yes): 2줄 — 경고 문구 또는 기호로 표시 ⚠원문 확인
- 표시 방법: 제품 또는 최소단위 포장마다 보기 쉬운 곳에 한글로 표시
- 원문 오류·주의: 표시 예시 수입자명이 "아동용섬유제품나라"로 다른 품목에서 복사됨(예시값이라 영향 없음)

## K-04 어린이용 가죽제품 · 공급자적합성확인
- 적용기준: 공급자적합성확인기준 부속서 1 어린이용 가죽제품 (+ 어린이제품 공통안전기준)
- 적용범위: 36개월 이상 만 13세 이하 어린이가 사용하는 가죽제품 (36개월 미만은 안전확인기준 부속서 1의 세부분류)
- 원문: https://www.safetyguide.kr/indct/kid?id=4
- 생활용품 짝(만 14세 이상): 가죽제품 → **연령 등급 분기**
- 분기:
  - 수작업 상세 설계(본문 7.2): 연령(36개월 미만/어린이/13세 초과) → 형태(의류·가방·신발·기타) → 소재(천연·모피·인조 세부, 동물명) → 형태별 추가(안감·밑창) → 수입 여부
- 라벨: KC(번호 없음) · 어린이 공통 뼈대
- 원문 오류·주의: 세부분류 표가 섬유제품 표를 복사한 것
- 원문 오류·주의: 사용연령 작성요령(3세·8세 구간)과 "학생용 의자" 주석이 가구 페이지에서 복사됨
- 원문 오류·주의: 주의사항 번호 "4.1 인조가죽"은 3.2가 맞음
- 원문 오류·주의: "기타 가죽제품" 주의사항 본문 없음

## K-05 어린이용 롤러스케이트 · 공급자적합성확인
- 적용기준: 공급자적합성확인기준 부속서 7 어린이용 롤러스케이트 (+ 어린이제품 공통안전기준)
- 적용범위: 앞·뒤에 각 2개 바퀴를 병렬로 단 것으로 구두 장착부 최대 길이 180 mm 이상. 탈착식·비탈착식 신발 포함
- 원문: https://www.safetyguide.kr/indct/kid?id=5
- 생활용품 짝(만 14세 이상): 롤러 스케이트 → **연령 등급 분기**
- 분기:
  - **적용 제외 확인**: 바퀴에 베어링이 없어요 → K-18로 전환 / 구두 장착부 길이가 180 mm 미만이에요 → 전문가 확인
  - **어떤 용도인가요?**: 레저용 / 경기용
- 라벨: KC(번호 없음) · 어린이 공통 뼈대 + 추가: 크기·체중의 한계
- 사용설명서 (부속서 7의 6.3): 1줄 — 별도 조립 부품이 있으면 조립 요령, 사이즈 맞추는 방법, 보관방법 등
- 사용상 주의사항: 1줄 — (부속서 7의 6.2 원문 확인 필요) ⚠원문 확인
- 표시 방법: 사용상 주의사항은 제품·포장 외 한글 사용설명서에 별도 표시 가능
- 원문 오류·주의: 작성요령에 방한용 마스크 문장이 섞여 있음(섬유제품 페이지에서 복사)

## K-06 어린이용 물놀이기구 · 안전인증
- 적용기준: 안전인증기준 부속서 1 어린이용 물놀이 기구 (+ 어린이제품 공통안전기준)
- 적용범위: 만 13세 이하 어린이의 부양을 돕는 물놀이기구. 공기주입식 물놀이기구와 수영보조용품(착용형·비착용형). 에어매트리스·에어베개·비치볼처럼 물에서 쓸 우려가 있는 제품 포함
- 원문: https://www.safetyguide.kr/indct/kid?id=6
- 생활용품 짝(만 14세 이상): 공기주입 물놀이기구, 공기주입보트, 수영보조용품(착용형), 수영보조용품(비착용형) → **연령 등급 분기**
- 분기:
  - **적용 제외 확인**: 가정용 어린이 풀(수영장)이에요 → 대상 아님
  - **어떤 제품인가요?**: 공기를 넣어 노는 물놀이기구 (튜브, 에어매트, 비치볼 등) / 몸에 착용하는 수영보조용품 (암링, 수영조끼 등) / 손으로 잡거나 끼우는 수영보조용품 (킥판, 풀부이 등)
- 라벨: KC + 안전인증번호 · 어린이 공통 뼈대 + 추가: 크기·체중의 한계; 사용 재료명·치수(내경×외경); 정보 및 경고문구 [수영보조용품에 한함]
- 사용상 주의사항 (공기주입 물놀이기구) (조건: water_toy_type = inflatable): 7줄 — 공기주입 물놀이기구는 구명기구가 아니며 수영장이나 풀장 등 안전한 곳에서만 사용하시오
- 사용상 주의사항 (수영보조용품) (조건: water_toy_type ∈ aid_wear/aid_hold): 4줄 — 공기를 주입하는 수영보조용품에 공기를 주입하는 방법, 공기를 제거하는 방법, 잠금장치의 사용법
